## Cloud & Infrastructure

- **Google Cloud for Startups (AI track)** – Generous cloud credits for AI-first startups plus support and training.  
- **AWS Activate** – Cloud credits, technical support, and training for startups building on AWS.  
- **Microsoft for Startups Founders Hub** – Azure credits, GitHub Enterprise seats, and AI tooling for early-stage startups.  
- **Cloudflare for Startups** – Credits for Workers, Pages, R2, D1, and security services to help startups ship on Cloudflare.  
- **Scaleway Startup Program** – European cloud credits with engineering support for early-stage startups.  
- **DigitalOcean Hatch** – 12 months of DigitalOcean credits plus mentorship and community.  
- **Oracle for Startups** – Oracle Cloud credits plus product expert access and co-marketing opportunities.  
- **IBM Startup Program** – IBM Cloud credits and tooling for startups building on IBM’s stack.  
- **Rabata Storage Grant** – Up to \$100,000 in S3-compatible storage credits for Gen‑AI startups. No VC requirement, no accelerator affiliation, no minimum spend required.

## AI & Developer Tools

- **ElevenLabs Grants** – Startups with fewer than 25 employees get 12 months of free access to ElevenLabs voice AI, including 33 million characters of text‑to‑speech and conversational agent usage.  
- **Claude for Startups** – Anthropic’s program for early-stage startups building with Claude. Companies founded within the last four years can get free Claude API credits, priority rate limits, and early access to new model releases.  
- **OpenAI Startup Credits (via partners)** – Free OpenAI API credits accessible through partner programs (e.g., cloud and fintech bundles).  
- **Perplexity API Startup Credits** – API credits for startups building on Perplexity’s search and answer engine.  
- **GitHub for Startups** – Platform credits for GitHub Enterprise, Copilot, Actions, and more for eligible startups.  
- **PostHog for Startups** – Credits and discounts for product analytics, feature flags, and experimentation.  
- **Datadog for Startups** – Monitoring and observability credits for cloud-native startups.  
- **Vercel for Startups** – Hosting and edge infra credits for startups building modern frontends.  
- **Supabase for Startups** – Postgres + auth + storage credits for startups choosing Supabase as their backend.  
- **Overloop CLI** – AI-powered outbound engine for startups. Source prospects from 450M+ contacts, launch email + LinkedIn campaigns, and manage conversations from the terminal. JSON output, agent‑native. Plans from \$69/mo.  
- **Signals CLI** – Intent signal monitoring CLI for startups. Track LinkedIn engagers, keyword posters, job changers, and funding events with JSON output for agent pipelines.

## Contributing

This list is community-maintained.

If you know a startup program, credit, or perk that fits this repo:

- Make sure it is:
  - Startup-focused (more than just a generic free tier)
  - Equity-free (no mandatory equity or revenue-share)
  - Publicly documented on an official program or product page

Then:

1. Open a pull request adding an entry under the right category, or  
2. Use an issue to suggest a new program.

Please keep descriptions short and neutral, and always include a direct link to the official program page.
